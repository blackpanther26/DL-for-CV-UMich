This repository contains my solutions and assignment implementations for the **Deep Learning for Computer Vision** course offered by the **University of Michigan**, taught by **Justin Johnson**.

The course covers the implementation of deep learning algorithms for computer vision, starting from basic linear classifiers to modern architectures like Transformers and Generative Adversarial Networks (GANs).

* **Institution:** University of Michigan

## 📂 Assignments Overview

| Assignment | Topic | Key Concepts Implemented |
| :--- | :--- | :--- |
| **A1** | **PyTorch & Linear Classifiers** | PyTorch Tensor API, k-Nearest Neighbors (kNN), Linear Classifiers (SVM, Softmax). |
| **A2** | **Neural Networks** | Two-layer Neural Net, Backpropagation, SGD, Momentum, Adam, Dropout, Batch Normalization. |
| **A3** | **Convolutional Neural Networks** | ConvNets (CNNs), Residual Networks (ResNet), data augmentation, training on CIFAR-10. |
| **A4** | **RNNs & Transformers** | Recurrent Neural Networks (RNN), LSTMs, Attention Mechanisms, Vision Transformers (ViT), Image Captioning. |
| **A5** | **Generative Models** | Object Detection (Single-Stage Detectors), Generative Adversarial Networks (GANs), Diffusion Models. |
| **A6** | **Visualizing & Advanced Topics** | Network Visualization (Saliency maps, fooling images), Style Transfer. |

*(Note: Depending on the specific semester offering, standard assignments usually cover the topics above. Adjust the table if your specific assignment list differed.)*
